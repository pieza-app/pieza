# Preguntas frecuentes

**¿Pieza es un framework?** Sí, pero no se instala como dependencia: las piezas se **copian** dentro de tu app y desde ahí son tuyas.

**¿Necesito una IA?** No. `pieza.py` funciona solo. Con una IA, crear una app es conversar.

**¿Qué licencia tiene?** Las piezas son MPL-2.0: si cambias un archivo de una pieza, compartes ese cambio, pero tu app puede tener
la licencia que quieras. Las herramientas son AGPL-3.0.

**¿Por qué Tauri y no Electron?** Tauri usa el navegador que ya trae el sistema. Las apps pesan mucho menos y hay un solo código
para Mac, Windows y Linux.

**¿Dónde se habla?** En [Discussions](https://github.com/pieza-app/pieza/discussions).
