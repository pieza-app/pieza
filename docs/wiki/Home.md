# Pieza

Pieza es una base abierta para hacer apps que viven en tu computador. Cada **pieza** es un módulo probado que resuelve una cosa:
tu IA, el idioma, el tema, las actualizaciones, el empaquetado. Una app nueva se arma eligiendo piezas, no escribiéndolas de cero.

## Por dónde empezar

- [Crear una app](Crear-una-app): el paso a paso, con tu IA o sin ella.
- [Las piezas](Las-piezas): qué hay y cómo se agregan a una app.
- [La app de escritorio](La-app-de-escritorio): cómo funciona el host (`host-tauri`) en Mac, Windows y Linux.
- [Mantener una app al día](Mantener-una-app-al-dia): versiones, «Pieza al día», Dependabot y publicar.
- [Aportar](Aportar): proponer una pieza, una mejora o una app hecha con Pieza.
- [Preguntas frecuentes](Preguntas-frecuentes).
